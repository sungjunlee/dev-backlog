## Method

`outcome-conformance.js` created a clean Git workspace for each fresh session,
copied the candidate skills, removed inherited provider credentials, and
recorded authority/rail argv, exit status, and before/after file hashes. GitHub
used only the controlled `gh` fake. One Backlog.md lifecycle scenario delegated
through the recorder to the real 1.50.1 CLI in a throwaway `--no-git` local
repository. Final-answer prose was retained for audit but was not graded.

Runner: Codex CLI `0.153.4`, model `gpt-6-astra`, low reasoning,
workspace-write sandbox. The clean retained run passed all twelve scenarios on
its first attempt; no pre-command timeout or isolated timeout retry occurred.
The retained command was:

```bash
node tests/evals/outcome-conformance.js \
  --model gpt-6-astra \
  --reasoning low \
  --backlog-bin /tmp/dev-backlog-503-backlog/node_modules/.bin/backlog \
  --output docs/conformance/2026-11-12-outcome-503
```

Backlog.md 1.50.1 was installed outside the worktree with:

```bash
npm install --prefix /tmp/dev-backlog-503-backlog \
  --cache /tmp/dev-backlog-503-npm-cache backlog.md@1.50.1
```
